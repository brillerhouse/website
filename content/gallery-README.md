# Inspiration gallery

The current edition covers **12 styles × 7 room types × 3 versions = 252 concepts**. `gallery-catalogue.json` defines localized room/style descriptions. `gallery-variants.json` defines Economy, Budget and Premium specifications, Small/Medium/Large categories, and the 252 individual variants. Each room/style gets every specification and every size distributed across its three versions; this is intentionally not the nine-combination budget/size Cartesian product. Budget does not determine room size.

`gallery-variant-generation.json` contains the 36 exact image-set generation briefs. Each image set covers one style and one specification, with seven room scenes plus an unused entrance scene in a two-column/four-row layout. `gallery-variant-prompts.json` contains 252 standalone image-generation prompts. Neither generation file is imported into the client bundle. The earlier `gallery-generation.json` records the superseded image edition.

The selective geometry review is recorded in `gallery-geometry-review.json`: 43 scenes were replaced for specific roof/window junctions, curved glazing or arched openings; 209 renders were preserved. Coherent rectangular rooms, ordinary faceted bay windows with flat panes and a few believable timber roofs remain. Source assets are retained byte-for-byte. `gallery-geometry-generation.json` records five correction sets (eight scenes each) and three standalone featured-image edits. Only the flagged variants and their standalone generation briefs were updated. The original 36 generation briefs remain historical records of the source edition. The six original references are unchanged.

New WebP assets are in `public/images/gallery/<style>-<specification>.webp`. Each variant has a normalized crop isolating its photograph and excluding scene boundaries; the UI uses an SVG viewport to preserve framing across card, curation and dialog layouts. Review crops if replacing any image set. Asset source dimensions are 1024×1536. The three opening variants also have larger standalone `featured-<variant-id>.webp` images, used throughout their cards and previews via `detailImage` to avoid enlarging a thumbnail on desktop.

Reviewed variants use `geometry-review-01.webp` through `geometry-review-05.webp`, with independent crops; the three corrected opening photographs use `reviewed-<variant-id>.webp`. Natural construction is the priority: level ceilings, straight rectangular windows and doors, clear lintels/supports, ordinary daylight, and credible material/fixture junctions. Avoid adding sloped rooflight wells, bowed glass or decorative arches merely to make an image look architectural.

`lib/gallery.ts` interleaves rooms/styles/specifications in the library, selects three opening directions and builds the localized copyable redesign prompt for each variant. Prompts preserve the uploaded photo's geometry and describe appropriate specification/size choices rather than inventing new architecture in the customer's room. Actual dimensions and prices are not claimed for reference images.

`components/Gallery.tsx` provides room, style, budget and size filters, 24-at-a-time pagination, a curated opening and three-way version switching within a preview. Some exact filter combinations legitimately have no matching version; the page offers a reset. The six original references in `gallery.json` remain a separate collection and the homepage continues to show three original references. References have no assigned budget/size, so they are omitted when those filters are active.

There is no automatic prompt transfer to the redesign app. Copy the prompt, open Briller, upload a photo and paste the brief. Clipboard rejection exposes a selectable prompt. Generated concepts remain labeled as such.

Run `BRILLER_PREVIEW=1 npm run build`, `npm run check` and `BRILLER_PREVIEW=1 npm test`. Gallery tests validate complete 252-concept coverage, independent budget/size allocation, localized prompts, 36 assets and valid crops, original-reference retention and standalone generation prompts. Browser checks should cover all variants, filtering, three-version switching, copying and clipboard rejection, pagination, dialog keyboard/focus behavior and desktop/mobile layouts.

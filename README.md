# Briller.house — marketing website

Двомовний сайт EN / UK для Briller. Next.js 15 + React 19 + TypeScript. Статичний export: усі сторінки мають готовий HTML і не потребують Node.js у production. Реєстрація, авторизація, генерація, білінг та кабінет залишаються на https://build.briller.house.

## Зміни з чату та локальний preview

Звичайні зміни з чату тепер публікуються в гілку `preview` без деплою. Для локального перегляду скопіюйте її, запустіть `npm run dev` та після оновлень виконуйте `git pull --ff-only`. У `dev` переносимо лише схвалену версію — це запускає Google Cloud Run. Детальні команди: [LOCAL-PREVIEW.md](deployment/LOCAL-PREVIEW.md).

## Запуск і перевірка

```bash
npm ci
npm run dev
```

Для production:

```bash
npm run build
npm run check
npm test
```

Результат — `out/`. Запускайте `npm run build`, а не тільки `next build`: додатковий крок генерує sitemap, robots.txt, llms.txt і мову HTML українських сторінок. `npm test` перевіряє локальні посилання й зображення, metadata, H1, hreflang, JSON-LD, мову HTML, noindex чернеток і контрольні значення тарифів.

## Швидке редагування

- `content/en.json`, `content/uk.json`: тексти, FAQ, підписи, навігація.
- `content/plans.json`: єдине джерело цін, кредитів, лімітів і пакунків.
- `content/gallery.json`: фотографії, фільтри та двомовні назви.
- `content/mike.json`: зображення аватара Mike Briller, YouTube-посилання й статуси порад щодо бюджету та будівництва.
- `content/legal.json`: юридичні чернетки обома мовами.
- `lib/content.ts`: канонічний домен, адреса застосунку, email.
- `app/globals.css`: кольори, шрифти, адаптивність і дизайн.
- `components/Pages.tsx`: структура сторінок.
- `components/UI.tsx`: інтерактивні елементи.
- `content/llms.txt`: стислий опис продукту для агентів; оновлюйте після змін тарифів.

Після редагування перебудуйте сайт і оновіть `out/` або Docker image. CMS не потрібна; AI може редагувати JSON і компоненти через репозиторій.

## Сторінки

`/en/` і `/uk/`, а також `features/`, `use-cases/`, `gallery/`, `pricing/`, `faq/`, `contact/`, `privacy/`, `terms/`, `refunds/`, `cookies/` під кожною мовою. `/` містить англійську сторінку як fallback, а Nginx перенаправляє його на `/en/`. Однакові канонічні сторінки EN і UK мають взаємні hreflang, x-default, Open Graph, Twitter metadata та JSON-LD Organization, WebSite, BreadcrumbList; FAQPage є на довідкових сторінках. Юридичні чернетки мають noindex і виключені із sitemap.

## Робочі інтеракції

- Мобільне меню та перемикання мови зі збереженням поточної сторінки.
- Щомісячні / річні тарифи й річний підсумок. Знижка: до 20%, Studio має інший відсоток.
- Фільтри кімнат і стилів, лайтбокс (Escape, фокус повертається до кнопки), завантаження референсу.
- Відкриття студії для ручного додавання мудборда. Автоматична передача відсутня за поточним станом застосунку.
- Порівняльний повзунок: ілюстративна зміна світлового ефекту на одному фото, чітко позначена як демонстрація, а не рендер Briller.
- Контактна форма перевіряє поля й згоду, відкриває mailto до hello@briller.house. Резервний текст можна скопіювати. Сайт не надсилає листи самостійно; потрібен налаштований поштовий клієнт користувача. Для серверного надсилання потрібен окремий API.

## Розгортання

### Статичний хостинг / VPS

Скопіюйте вміст `out/` у web root Nginx. `deployment/nginx.conf` — готова конфігурація статичного сервера з портом 8080, справжніми 404, gzip і заголовками. Змініть `root` на свій каталог. Доступ на читання: `chmod -R a+rX out`. HTTPS, DNS і сертифікат налаштуйте на зовнішньому reverse proxy. Канонічний домен — `briller.house`, `www` має перенаправлятися на нього.

### Docker / VPS

```bash
docker compose -f deployment/compose.yaml up -d --build
```

Маркетинговий контейнер буде доступний на `127.0.0.1:8080`. Приклад зовнішнього TLS reverse proxy — `deployment/host-nginx.example.conf`: потрібно підтвердити шляхи сертифікатів. Збережіть поточний virtual host застосунку `build.briller.house`. Сайт і застосунок розгортаються окремо та можуть працювати на одному сервері.

### Google Cloud Run

Зберіть Docker image, опублікуйте у вашому Artifact Registry й розгорніть на Cloud Run із container port 8080. Налаштуйте public access для маркетингового сервісу та домен через вашу наявну GCP-інфраструктуру. Не використовуйте приватні Firebase/Stripe ключі в маркетинговому frontend: цей сайт їх не потребує.

Docker-конфігурацію підготовлено; Docker image у цьому середовищі не збирали.

## Що підтвердити до публічного запуску

1. **Юридичні дані**: компанія, адреса, юрисдикція, дата чинності; retention, регіони обробки, провайдери, AI-training use, права користувачів; скасування, повернення, failed-generation credits і комерційна ліцензія. Чернетки не є завершеними політиками. Після перевірки приберіть draft banner, змініть robots metadata та включіть їх у sitemap.
2. **Тарифи**: звірте з фактичним Stripe checkout. Місячні ціни й ліміти взято з наданого опису. Річні суми: Explorer $95.88, Pro Design $239.88, Studio $719.88. Деякі можливості старших планів показані як включені за логікою ієрархії; остаточний набір звірте з entitlement-кодом застосунку. Free-ітерації не прирівнюйте до кредитів.
3. **Реальні результати**: замініть фото-референси на дозволені реальні результати Briller для демонстрації якості. Не видавайте поточну добірку за community gallery або власні генерації. Відгуки та метрики не вигадані й не додані.
4. **Застосунок**: перевірте CTA і реєстрацію. Маркетинговий сайт не перевіряє стан Firebase, Stripe чи AI backend.
5. **Email**: переконайтеся, що hello@briller.house приймає пошту. За потреби підключіть серверний API надсилання, rate limiting і захист від спаму.
6. **SEO**: додайте домен і sitemap у Google Search Console / Bing Webmaster Tools. Не додавайте аналітику або сторонні embeds без перевірки privacy/consent. llms.txt є допоміжним файлом, а не гарантією присутності в AI-пошуку.

## Вибір мови

EN / UK знаходиться у спільному footer. Ручний вибір зберігається у браузері й має пріоритет над автоматичним визначенням країни. Без вибору браузер звертається до `https://api.country.is/` (без cookies провайдера й referrer сторінки). IP з України → відповідна українська сторінка; шлях, query та hash зберігаються. Інші країни й помилки не змінюють відкриту мову. Timeout — 2,5 с; код країни кешується на 24 години, невдала перевірка — на 10 хвилин. IP у сховищі сайту не записується.

`lib/locale-routing.ts` — правила; `components/LanguagePreferences.tsx` — footer та перевірка. Для власного сервера з CSP дозвольте `https://api.country.is` у `connect-src`; готовий Nginx конфіг уже містить правило. Локально країна визначається за публічною IP-адресою браузера. Юридичні чернетки описують використання геосервісу й мовного сховища.
